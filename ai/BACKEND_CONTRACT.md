# SentinelFlow — AI / Backend Integration Contract

This document defines the contract between the AI/Security-Intelligence module (**Member 1**) and the Backend/API team (**Member 2 / Teammates**).

---

## Endpoint Specification

### `POST /analyze`

Analyzes a detected security incident and generates a structured, explainable Attack Story with non-destructive response recommendations.

---

### Request Payload

**Content-Type:** `application/json`

```json
{
  "incident_id": "INC-BF-001"
}
```

#### Fields:
- `incident_id` (string, required): The unique identifier of the incident generated by the deterministic detector (e.g., `INC-BF-001`, `INC-PE-001`, `INC-RA-001`).

---

**HTTP Status:** `200 OK`  
**Content-Type:** `application/json`

```json

  "incident_id": "INC-BF-001",
  "attack_type": "BRUTE_FORCE_SUCCESS",
  "confidence": 0.95,
  "summary": "A sequence of repeated failed authentication attempts was followed by a successful login for the same account and source IP.",
  "attack_progression": [

    "The failed attempts originated from the same source IP.",
    "A successful login followed the failed attempts.",
    "The sequence is consistent with a successful brute-force attack."
  ],
  "evidence": [
    {
      "event_id": "EVT-0001",
      "event_type": "login_failed",
      "reason": "Failed authentication attempt relevant to the brute-force sequence."
    },
    {
      "event_id": "EVT-0002",
      "event_type": "login_failed",
      "reason": "Failed authentication attempt relevant to the brute-force sequence."
    },
    {
      "event_id": "EVT-0003",
      "event_type": "login_failed",
      "reason": "Failed authentication attempt relevant to the brute-force sequence."
    },

```

---

### Error Responses

#### `404 Not Found` (Incident does not exist)
```json
{
  "error": "Incident INC-999-001 was not found."
}
```

#### `400 Bad Request` (Invalid request body)
```json
{
  "error": "Invalid request payload. Must contain 'incident_id'."
}
```

## Python Integration Example for Backend Teammate

Backend code can directly import and call `analyze_incident_api`:

```python
from ai.contract import analyze_incident_api

# Example controller / FastAPI route handler
def handle_analyze_request(request_data: dict):
    try:
        attack_story = analyze_incident_api(request_data)
        return {"status": "success", "data": attack_story}, 200
    except ValueError as exc:
        return {"error": str(exc)}, 404
```

---

## Security Guarantees & Contracts

1. **Non-Execution**: The `recommendation.executed` flag is ALWAYS `false`. The AI never executes destructive actions.
2. **Human Approval**: The `recommendation.requires_human_approval` flag is ALWAYS `true`.
3. **Data Protection**: Security logs and usernames are treated strictly as untrusted data.
4. **Hallucination Prevention**: Every `event_id` listed in `evidence` is guaranteed to exist in the underlying security event context.
